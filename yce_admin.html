YCE Site Administration
Youth Camp & Exchange — MD 112 Belgium · edits are committed to GitHub, the site republishes itself
How it works. This page edits the repository directly through the GitHub API — there is no separate server. You need a GitHub account with write access to the repository and a fine-grained personal access token (GitHub → Settings → Developer settings → Fine-grained tokens: this repository only, permission Contents: Read and write). After each save, a GitHub Action rebuilds the embedded templates and camps.json, then GitHub Pages republishes the site (2–3 minutes).
